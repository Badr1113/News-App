# News App

A Flutter news app with a home screen, category cards, and a settings drawer.

## Project structure

- `lib/main.dart`: application entry point.
- `lib/app.dart`: app root and theme-mode state.
- `lib/core/config/`: app configuration and light/dark themes.
- `lib/core/sources/`: shared asset paths and color palette.
- `lib/features/home/`: home screen, category model, drawer, and category card.
- `lib/assets/images/categories/`: bundled category images.

Run the app with `flutter run` and tests with `flutter test`.
